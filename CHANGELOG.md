# Changelog - YoPlayer

All notable changes to YoPlayer are documented in this file.

## [0.1.0] - 2026-03-30

### 🚀 Branding & Infrastructure
- Complete project rebranding to **YoPlayer** (`open.yo.player`).
- Application ID updated to `open.yo.player`.
- Source tree restructured to `open/yo/player/`.
- App version set to `v0.1.0`.

### 🎨 UI & Player Customization
- Added **Player View Customizer ("Вид плеера")** under *Settings ➔ Appearance*:
  - **Track Title Alignment**: Choose **Left** or **Center** alignment for song title and artist.
  - **Track Title Position**: Place song title **Below Artwork** or **Above Artwork**.
- Cleaned up top bar: removed Cloud Streaming icon, version badge, and changelog button.
- Removed Accounts section from Settings.
- Refactored **About** screen: YoPlayer v0.1.0, GPL-3.0 license info, fork attribution, and repository link `https://github.com/RDKGL/YoPlayer`.

### 🎧 Audio & Performance
- Added **"Доступ к лучшему звучанию через USB"** toggle in *Settings ➔ Playback* for direct audio output to USB DACs and IEM headphones.
- Removed startup splash screen delay for **instant app launch**.

### 🌍 Localization
- Added native string translations across **all 13 supported languages** (English, Russian, German, Spanish, French, Italian, Korean, Chinese, Turkish, Vietnamese, Arabic, Indonesian, Norwegian).
