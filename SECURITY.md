# Security Policy - YoPlayer

## Reporting A Vulnerability

Please report security issues privately through GitHub Security Advisories or by opening an issue on [github.com/RDKGL/YoPlayer](https://github.com/RDKGL/YoPlayer).

Do not post secrets, credentials, or exploit details publicly.

## Supported Versions

Security fixes target the latest public release (`v0.1.1`) and the `main` branch.
